# Nguyen-Hoai-Que-Tran

A 20/10 gift website. Vite + React + TypeScript + Tailwind CSS + Motion.

## Edit the content

All text (name, letter, reasons, surprise message) lives in [`src/content.ts`](src/content.ts).

## Run locally

```bash
npm install
npm run dev
```

## Deploy (free)

Push to GitHub, then import the repo at [vercel.com/new](https://vercel.com/new). Vercel detects Vite automatically; no config needed.
